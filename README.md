## About me

Engineer who works at the customer boundary: finds the friction between customers, product, and engineering, then builds the workflow, integration, or tool that removes it. Nearly a decade in customer-facing technical roles, the last several years building the software behind them.

## Professional experience

- Designed and shipped **_shftr_**, a workforce-management and ticket-routing system: React, Node, and MongoDB first, then refactored to a Go backend on Datastore inside FullStory's production stack. Skills-based routing cut median first response on sensitive compliance tickets by 75%. Now in its third iteration, serving as a headless service connecting Assembled with Zendesk's Unified Agent Statuses. [[demo](https://youtu.be/u1l6P-yYj6w)]
- Designed and built **Support Bridge**, an integration service connecting Slack, an internal customer-record system, and Linear — automating ticket creation, routing, escalation webhooks, and agent assignment for a 14-person support organization in place of manual triage.
- Partnered with sales engineering on a marquee EMEA opportunity: mapped the prospect's multi-domain customer journey, designed a cross-domain session-stitching approach across three live sites, and wrote the sample code that demonstrated feasibility and guided their implementation.
- Built the infrastructure behind FullStory's demo and prototyping program: a Next.js starter that stands up a working demo environment with one command, every GCP resource defined in Terraform, and internal tools put behind the company's auth layer, with least-privilege access roles derived from an audit of past permission requests.
- Adopted an abandoned public Sanity plugin that was blocking customer Studio upgrades with dependency conflicts: refactored the codebase, added tests and CI, and republished it to npm as [`sanity-plugin-singleton-management`](https://www.npmjs.com/package/sanity-plugin-singleton-management). Weekly downloads grew from roughly 40 at relaunch to more than 2,400.
- Built most of a customer-facing self-service support portal and the reporting foundation behind it, using AI-assisted prototyping to move from sketch to working software in days rather than weeks.
- Extended Sanity's Vision query playground into a natural-language-to-GROQ tool — MCP server, custom UI, backend services — prototype to internal demo in days, which got engineering leadership and a cofounder discussing productizing it.
